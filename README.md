# Nifty feedback

Bug reports and ideas for the **Nifty** extensions for VS Code, Cursor, Windsurf, VSCodium and other editors that use Open VSX.

**Maintained. No sign-in. No telemetry.**

- **Found a bug?** [Open a bug report](https://github.com/get-nifty/feedback/issues/new?template=bug.yml). Say which extension, and include the versions and any error from the Output panel.
- **Have an idea?** [Suggest a feature](https://github.com/get-nifty/feedback/issues/new?template=feature.yml), for an existing extension or a new one.
- **Before you open an issue,** [search the existing ones](https://github.com/get-nifty/feedback/issues). If yours is already there, a 👍 on it helps decide what gets done first.
- **Pro licences and payments:** see [getnifty.dev](https://getnifty.dev).

Every extension is listed at [getnifty.dev](https://getnifty.dev), on the [Visual Studio Marketplace](https://marketplace.visualstudio.com/publishers/nifty) and on [Open VSX](https://open-vsx.org/namespace/nifty).
